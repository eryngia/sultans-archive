Text:

アルミナ嬢が再びやって来て、応接間に堂々と座っている。彼女が身につけているまばゆい宝飾品のおかげで、気づかないほうが難しい。 「父上以外の殿方に、少し聞きたいことがあるわ。知り合いの殿方の中で少し地位があるのは、あなただけだから」彼女はあなたを見つめながら言った。どうやら、この傲慢なお嬢さんの無作法を指摘できる者はいないようだ。「答えてくれる？」

5321052_prompt_1

Text:

あなたの言葉により彼女の顔は赤くなりました。どうやら、これまで誰も彼女の無礼な口調を指摘したことがなかったようです。 「私の口調……どうしたの。私の口調――これが私の口調。これでいいのよ！」 あなたは答えませんでした。 しばらくして、彼女は服の端についた純金の鈴を指でいじりながら、不満げに小声で言いました。「その……ええと……たぶん、たぶん『あなた様』と言うべきかもしれません。」 それは完全な改善とは言えませんが、それでも進歩と言えるでしょう。

Text:

彼女の質問は簡単でした。「いったいどんな男性が結婚に値するの？」 彼女が挙げた花婿候補の中に、驚くことにスルタンまで含まれているのを見て恐ろしくなりました……そのほかには首都のあらゆる優れた若い男性たちが含まれていました。彼女は当然のように彼ら全員に可能性があると考えており、自分が好きかどうかだけで選ぶつもりのようです。 あなたは彼女が父親にどれほど甘やかされてきたのかを考えながら、慎重にあなたの意見を述べました……

5321052_prompt_2

Text:

「強い男！大好き！超好き！」彼女は息を切らしながら激しく同意を示しました。「特にあのきれいな脚が好き……男は走るのが速くなくては、決闘の時に捕まって殺されてしまうわ！」 あなたは「決闘」という言葉の意味について彼女を訂正したいと思いましたが……まあいいか、とあきらめました。どうせ今の彼女には耳に入らないでしょうから。 「でも勇敢な男ってどこにいるの？うーん……道場？でもあそこには脂ぎった金持ちの御曹司しかいない……それとも戦場かしら？」 彼女は首をかしげ、幼いながらも貴族の衣服や美しいアクセサリーに関係のない考えを少し巡らせているようでした。しばらくすると、彼女は勢いよく首を振りました。 「もういい——とにかくこれを渡すわ、相談料！」

Option 5:

Prompt:

ID:

5321052_prompt_3

Text:

あなたは彼女に、筋肉は老い、金は消え、権勢は裏切るが、知恵だけは永遠にあなたとともにあると伝えました。 「でも、賢い男たちはいつも賢い方法で女をだますんでしょう？私のパパだってそうやってママをだましたのよ……うーん、でもママも快適で裕福な暮らしをしてたし、うーん……」 彼女は何か考え込み、幼い頭の中には貴金属や華麗な衣装に関係のない事柄が詰まっているようでした。 「賢い男を見つけるのはいいかも。でも、その前提としてお金持ちで、ハンサムで、地位もある人じゃないと——そんな男が現れたら、大騒ぎになるわね！」 そう言いながら、彼女は首都の若い貴族の娘たちの間でのゴシップを楽しげに語り始めました。どれも浴場では聞けないような刺激的な話ばかりでした。

Icon:

Option 6:

Prompt:

ID:

5321052_prompt_4

Text:

「ねえ、あなたみたいな人のことよ？父が言ってたわ、あなたが不機嫌な時は、スルタンも不機嫌になるって。そして、あなたはいつもスルタンを喜ばせる方法を知っているって！」 彼女はそう言いながら真剣に考えているようでした。子供じみた顔つきが珍しくまじめに見えました。 「だから私は権臣を見つけるべきなのね。しかも、強くて、賢くて、男前な……権勢がある人はほかの人よりもすてきに見えるから。あなたみたいに！」 あなたはその言葉にどう答えればいいかわからないと彼女に伝えました。 彼女は大笑いしました。この冗談がとても面白いと思ったようです。去る時も、あなたがどれだけすてきで権勢があるか笑いながら話し、それがあなたの名声をさらに高めました。

Option 7:

Prompt:

ID:

5321052_prompt_5

Text:

「そういうことなら、私が結婚すべき相手はパパかもしれない。私が知る限り、お金を稼ぐのが一番上手な人だもの。どんな手を使ってでも。」 彼女はあなたの顔を見て、突然大笑いしました。 「冗談よ——あなたの顔ったら……本気にしてないでしょうね？私が父と結婚するわけない、太りすぎよ！」 その後、彼女はあなたの言葉を考え込むような様子を見せ、子供じみた顔には珍しく少し真剣さが漂いました。 「お金を稼ぐ男が一番いい男。あなたの言うことは正しいかもしれない。稼げるなら、勇士でも、策士でも、大臣でも、何だってお金で手に入るもの……」 彼女は飛び上がるように立ち上がると、あなたにお辞儀をして、何かを手渡しました。 「これが相談料よ。」
